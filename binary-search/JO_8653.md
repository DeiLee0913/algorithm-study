# 8653. 뾰족산

- **출처 / 링크:** [정올 8653 — 뾰족산](https://jungol.co.kr/problem/8653)
- **난이도·태그:** 실버 3 — 이분 탐색
- **상태:** AC
- **메인 아이디어(폴더):** binary-search
- **보조 태그:** unimodal, ascending-descending
- **풀이 위치:** `binary-search/JO_8653.java`

### 왜 어려웠는지 / 막힌 지점

- 처음엔 mountain을 **왼쪽·오른쪽 두 배열**로 나눠 따로 관리하려 했다.
- 하지만 결국 분리해도 오른쪽도 배열은 내림차순으로 찾아야 해서, 배열을 하나로 두고 `startIdx`, `endIdx`를 넣어 함수로 구현했다.

### 최종 풀이 요약

- 최댓값 인덱스 `maxIdx`(꼭대기)를 구한 뒤, 질의마다
  - 꼭대기면 `T`
  - 왼쪽 구간 `[0, maxIdx-1]` 오름차순 이분 탐색 → 있으면 `L`
  - 오른쪽 구간 `[maxIdx+1, n-1]` 내림차순 이분 탐색 → 있으면 `R`
  - 없으면 `N`
