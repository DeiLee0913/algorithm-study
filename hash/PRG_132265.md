# 132265. 롤케이크 자르기

- **출처 / 링크:** [프로그래머스 132265 — 롤케이크 자르기](https://school.programmers.co.kr/learn/courses/30/lessons/132265)
- **난이도·태그:** Lv.2 — 해시
- **상태:** AC
- **메인 아이디어(폴더):** hash
- **보조 태그:** hashmap, hashset, one-pass
- **풀이 위치:** `hash/PRG_132265.java` (초기 시도: `hash/PRG_132265_TwoSets.java`)

### 왜 어려웠는지 / 막힌 지점

- 처음엔 **두 개의 Set**으로 접근했다가 시간 초과.
- 자르는 위치 `s`를 옮길 때마다(O(N)) 왼쪽·오른쪽 요소를 처음부터 다시 HashSet에 넣어 O(N)이라, 전체가 **O(N²)**.

### 최종 풀이 요약

- 전체를 먼저 `HashMap`에 넣어 두고(오른쪽), 앞에서부터 하나씩 `HashSet`(왼쪽)으로 옮기면서 맵에서 개수를 줄인다.
- 맵에서 개수가 0이 되면 키를 제거해 **남은 종류 수**를 유지한다.
- `map.size() == set.size()`인 위치를 세면 공평한 자른 방법의 수.

### 참고한 것

- Map과 Set을 함께 쓰는 방향 — **AI** 조언. 그 방향으로 다시 접근해 AC.
