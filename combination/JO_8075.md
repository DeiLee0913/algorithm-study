# 8075. 안녕

- **출처 / 링크:** [정올 8075 — 안녕](https://jungol.co.kr/problem/8075) (백준 [1535](https://www.acmicpc.net/problem/1535)와 동일)
- **난이도·태그:** 실버 1 — 조합, DFS
- **상태:** AC
- **메인 아이디어(폴더):** combination
- **보조 태그:** knapsack, 0-1 knapsack, 완전탐색
- **풀이 위치:** `combination/JO_8075.java`

### 잘한 점

- 재귀로 “친구를 하나씩 보면서 인사할지 말지”라는 골격은 스스로 잡았다.
- 체력이 0 이하이면 그 가지는 버리고, 친구를 다 본 뒤에 기쁨을 갱신하는 종료 조건도 맞았다.

### 왜 어려웠는지 / 막힌 지점

- 재귀 골격은 잡았는데, `for`로 다음 친구를 고르며 `visited`를 돌리는 **순열**처럼 짰다. 인사 순서는 답이 바뀌지 않는데 순서까지 나열해서 \(n!\)에 가깝게 커졌고, 예제는 대부분 맞는데 **마지막 예제에서 TLE**가 났다.
- 이 문제는 친구마다 **한다 / 안 한다** 두 갈래만 생각해 조합으로 구성하면 된다. `idx`를 넘겨서 포함·미포함만 타면 \(2^{20} \approx 100\)만이라 통과한다.

### 최종 풀이 요약

체력 100에서 시작해, 친구 \(i\)에게 인사하면 체력 \(L[i]\)를 잃고 기쁨 \(J[i]\)를 얻는다. 체력이 0 이하가 되면 기쁨은 0. 한 사람당 최대 한 번.

제출 코드는 DFS:

- `dfs(idx, hp, joy)`
- `hp <= 0`이면 return
- `idx == n`이면 `max_joy` 갱신
- 인사: `dfs(idx+1, hp-L[idx], joy+J[idx])`
- 스킵: `dfs(idx+1, hp, joy)`

같은 선택은 0-1 배낭으로도 된다. 용량은 **99**(0이 되면 죽음), 무게는 잃는 체력, 가치는 기쁨. `w`를 뒤에서 앞으로 돌리면 같은 친구를 두 번 쓰지 않는다.

### 새로 알게 된 것 / 다음에 쓸 것

- “고른다/안 고른다”는 순열이 아니라 **조합(포함·미포함)**. `for + visited`는 순서가 필요할 때만.
- \(n \le 20\)이면 \(2^n\) DFS로도 되고, 같은 그림이 0-1 배낭 DP다.
- 배낭에서 용량을 100이 아니라 **99**로 두는 이유: 체력 0은 죽음.

### 참고한 것

- AI: 처음 독립 계산이 틀린 이유, TLE가 순열 DFS 때문이라는 점, 포함/미포함 두 갈래로 바꾸라는 피드백.
